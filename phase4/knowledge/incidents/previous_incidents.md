## Incident INC-8821: Fiber Degradation on NYC-HQ Link
- **Date**: 2025-11-12
- **Root Cause**: Micro-bends in physical fiber path causing intermittent optical signal degradation.
- **Observation**: Interface errors increased before BGP neighbor session dropped.
- **Resolution**: Traffic was temporarily shifted to IPSec backup underlay path while provider repaired fiber splice.
